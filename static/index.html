MANUAL INSTALL
IMPORT MODEL FOLDER Point OpenBGR at a checkpoint folder you downloaded yourself, for example from huggingface.co or with `hf download ZhengPeng7/BiRefNet`. The model is detected automatically, and a folder holding several checkpoints imports them all. Files are copied into the cache shown above.
